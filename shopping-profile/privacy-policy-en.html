Shopping Profile Privacy Policy

Effective date: July 1, 2026

This page explains how the iOS app "Shopping Profile" handles user information.

1. Information We Collect

This app does not collect personal information.

This app does not use account registration, login, in-app purchases, advertising, analytics, or tracking.

Information entered by the user, such as names, sizes, brands, preferences, and notes, is handled on the device for displaying, editing, copying, file sharing, and importing within the app.

2. Local Storage

Information entered by the user is stored locally on iOS.

Saved information can be deleted from within the app or by deleting the app from the device.

3. Data Transmission

This app does not send information entered or saved by the user to the developer's server.

This app does not use external APIs, a custom backend, or cloud sync.

4. Copy Feature

This app allows users to review saved information and copy it to the clipboard through an explicit user action.

If copied content is pasted into another app or service, that app or service handles the content according to its own terms and privacy policy.

5. Sharing and Import Features

This app allows users to share their own profile as a file through an explicit user action. Items marked as not shared are not included in the shared file.

If a shared file is sent through AirDrop, Messages, LINE, email, the Files app, or another service, that service handles the file according to its own terms and privacy policy.

A received profile is saved on the device only when the user enters a name and imports it. The user's own profile is not automatically overwritten.

6. App Lock

This app can use optional app lock with Face ID, Touch ID, or the device passcode when enabled by the user.

Authentication uses standard iOS functionality. This app does not obtain or store biometric authentication information.

7. User Review of Personal Information

This app does not automatically detect or anonymize personal or sensitive information.

Please review the content before copying or sharing it.
