Pitch Note Checker Support

"Pitch Note Checker" is an iOS app that analyzes sound from the microphone and shows note names in real time.

What You Can Do

  • Real-time note name display from microphone input
  • Switch between solfege and ABC notation
  • Review detected note history
  • Copy note history

Related Tools

  • Hz Piano - Play test tones from a frequency or keyboard.

Basic Usage

  1. Open the app.
  2. Tap the start button.
  3. Allow microphone access.
  4. Play a sound or speak.
  5. Review the displayed note name and history.
  6. Switch between solfege and ABC notation as needed.
  7. Tap stop to end analysis.

FAQ

  1. Is audio saved?

    No. This app does not save recorded audio.

  2. Is audio data sent to a server?

    No. Audio data is not sent to the developer's server or a third-party server.

  3. Can the displayed note name be off?

    Yes. Background noise, overtones, volume, distance from the microphone, and device conditions may cause the displayed note to differ from the actual sound.

  4. Can I use it as a tuner or transcription app?

    This is a simple app for checking note names. It does not guarantee complete transcription or professional tuning.
