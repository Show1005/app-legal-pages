Pitch Note Checker Privacy Policy

Effective date: June 13, 2026

This Privacy Policy explains how the iOS app "Pitch Note Checker" handles user information.

1. Information Collected

Microphone input is analyzed on the device in real time to display note names.

2. Microphone Input

Microphone input is used only to analyze surrounding sound and display note names.

This app does not save recorded audio.

This app does not send audio data to the developer's server or a third-party server.

Detected note history is handled for display and copy features inside the app. The audio itself is not saved.

3. Data Transmission

This app does not send user audio data, note history, device information, or usage data to the developer's server.

This app does not use external APIs or a custom backend.

4. External Services

This app does not use advertising SDKs, analytics SDKs, third-party tracking tools, or external services for user identification.

5. Disclaimer

This app is a tool for helping check note names based on surrounding sound.

Background noise, overtones, volume, device state, and microphone distance may cause displayed note names to differ from the actual sound.

This app does not guarantee complete transcription, professional tuning, or musical judgment accuracy.
