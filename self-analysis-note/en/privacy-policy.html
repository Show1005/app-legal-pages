Self Analysis Note Privacy Policy

Effective date: June 24, 2026

This page explains how the iOS app "Self Analysis Note" handles user information.

1. Information Collected

Career history, experiences, certifications, interests, strengths, hobbies, values, notes, and other information entered by the user are handled on the device for display, editing, reviewing, and copying self-analysis memos.

2. Local Storage

Information entered by the user is stored in iOS local storage.

Stored information can be deleted inside the app or by deleting the app.

3. Data Transmission

This app does not send information entered or saved by the user to the developer's server.

This app does not use external APIs, a custom backend, or cloud sync.

4. Copy Feature

Users can review registered content as a self-analysis memo and copy it to the clipboard through an explicit user action.

If copied content is pasted into another app or service, handling by that destination follows that service's terms and privacy policy.

5. Personal Information Review

This app does not automatically detect or anonymize personal information.

Please review the content before copying a self-analysis memo.

7. Changes
