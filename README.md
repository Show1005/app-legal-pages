# app-legal-pages

Public legal and support pages for small iOS apps published with GitHub Pages, under the Lillip Apps brand.

## Current apps

Each app gets its own top-level directory (e.g. `shomikigen-check/`, `nfc-setup/`). The current list of apps is maintained in `index.html`, not here.

## Pages

Each app provides:

- Privacy Policy
- Support

Some apps may also provide small web tools related to the app.
