# app-legal-pages

Public legal and support pages for small iOS apps published with GitHub Pages.

## Current apps

- `賞味期限チェック`
- `過去問周回カウンター`
- `サブスク管理｜更新日・解約通知`
- `音階チェッカー`
- `NFCタグセットアップ`

## Pages

Each app provides:

- Privacy Policy
- Support

Some apps may also provide small web tools related to the app.
