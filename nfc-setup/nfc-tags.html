NFCタグの選び方

このアプリでNFCタグを使うために、対応タグの種類と選び方をまとめました。

広告について: このページには楽天アフィリエイト等の広告リンクを含みます。リンク経由で購入されると、運営者が紹介料を受け取る場合があります。紹介している商品は、NFCタグセットアップでの利用を想定した参考情報です。

おすすめのタグ

NTAG213 / NTAG215 / NTAG216

iPhoneで使う場合は、以下のタグがおすすめです。

NTAG213 NTAG215 NTAG216
まず試すなら
NTAG213の丸型シールタイプで十分です。URL・テキスト・ショートカット起動などの用途に使えます。
Wi-Fiや長めのテキスト
容量に余裕のある NTAG215 / NTAG216 を選んでください。

動作確認したNFCタグ

YANZEO NTAG213 NFCタグ / 粘着ステッカー

144バイトメモリーのNTAG213タイプです。URL、テキスト、ショートカット起動などをまず試す用途に向いています。

実際に購入し、NFCタグセットアップでの利用を確認した商品です。

金属面に貼る場合

金属対応タグを選んでください

通常のNFCシールは、金属面に貼ると読み取り・書き込みがうまく動かない場合があります。金属面に貼る場合は、「金属対応」または「On-metal」と記載されたNFCタグを選んでください。

注意事項

ご利用の前に

  • 読み取り専用タグには書き込めません
  • ロック済みタグには上書きできません
  • すべてのNFCタグで動作を保証するものではありません
  • Wi-Fi接続やショートカット実行は、iOS側の仕様により確認が表示される場合があります
