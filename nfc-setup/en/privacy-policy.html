NFC Tag Setup Privacy Policy

Effective date: June 17, 2026

This page explains how the iOS app "NFC Tag Setup" handles user information.

1. Information Collected

URLs, Wi-Fi information, vCard information, text, shortcut names, and entered text are handled on the device for writing to NFC tags, displaying read results, and saving templates.

2. NFC Use

This app uses Core NFC to write information to NFC tags and read information from NFC tags.

Read NFC tag contents are handled for display, copy, edit-and-rewrite, and template saving inside the app.

3. Local Storage

If you save templates, the saved content is stored on your device.

Saved content can be deleted inside the app or by deleting the app.

4. Data Transmission

This app does not send information you enter, save, or read to the developer's server.

This app does not use external APIs or a custom backend.

5. Shortcut Launch Tags

This app can write URLs to NFC tags to launch shortcuts already created in Apple's Shortcuts app.

Execution confirmation and behavior depend on iOS and Shortcuts settings.

6. Notes

If you write Wi-Fi information or vCards that contain personal information, anyone who can read the NFC tag may be able to view that content.

NFC tag type, capacity, device, iOS behavior, and shortcut settings may prevent expected behavior.
