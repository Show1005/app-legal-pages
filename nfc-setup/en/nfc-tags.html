Recommended Tags

NTAG213 / NTAG215 / NTAG216

For use with iPhone, the following tags are recommended.

NTAG213 NTAG215 NTAG216
For a first test
An NTAG213 round sticker type is enough for first tests such as URLs, text, and shortcut launch tags.
Wi-Fi or longer text
Choose NTAG215 or NTAG216 when you need more capacity.

When Attaching to Metal

Choose On-Metal Tags

Standard NFC stickers may not read or write correctly when attached to metal. If you attach a tag to a metal surface, choose NFC tags labeled "metal compatible" or "On-metal".

Notes

Before Use

  • Read-only tags cannot be written to
  • Locked tags cannot be overwritten
  • Operation is not guaranteed for every NFC tag
  • Wi-Fi connection or shortcut execution may show confirmation depending on iOS behavior
