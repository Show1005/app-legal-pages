NFC Tag Setup Support

"NFC Tag Setup" is an app for creating information for NFC tags on iPhone.

What You Can Do

  • Create URL tags
  • Create Wi-Fi tags
  • Create vCard / business card tags
  • Create text tags
  • Create shortcut launch tags
  • Read, copy, edit, and rewrite NFC tags
  • Save templates

Prepare NFC tags

If you do not have NFC tags yet, check How to Choose NFC Tags for supported tag types and purchase notes.

For a first test, NFC tags labeled NTAG213, NTAG215, or NTAG216 are recommended.

Shortcut tags

Shortcut tags create a URL for launching a shortcut that already exists in Apple's Shortcuts app.

The shortcut name must exactly match the name in the Shortcuts app.

See Shortcut Samples for examples.

FAQ

  1. A shortcut does not launch.

    Check that the shortcut name exactly matches the name in the Shortcuts app.

  2. Can every tag store the same content?

    No. Writable content may differ depending on the NFC tag type and capacity.

  3. Is entered information sent to a server?

    No. Entered information is not sent to the developer's server.
