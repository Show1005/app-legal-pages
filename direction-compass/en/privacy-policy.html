Direction Compass Privacy Policy

Effective date: July 11, 2026 (Last updated: July 24, 2026)

This Privacy Policy explains how the iOS app "Direction Compass" handles user information.

Direction Compass shows the direction toward a destination or selected compass direction with an arrow. It does not provide maps, route guidance, or navigation. Place and address search uses Apple's built-in MapKit.

1. Information This App May Handle

This app does not collect personal information. This app may handle the following information:

  • Current location
  • Device heading
  • A place name or address the user types into the search field
  • Place name, address, and coordinates returned by Apple MapKit
  • A custom display name the user assigns to a saved place
  • Whether a place is saved, and when it was last used
  • An on-device random seed used for the "Daily Direction" feature
  • The currently selected destination or special direction type

2. Purpose of Use

This information is used only for the following purposes:

  • Calculating the bearing from your current location to a destination
  • Displaying the arrow and distance
  • Showing your saved and recently used places
  • Computing the "Daily Direction" on-device so it stays the same for the rest of the day
  • Displaying special directions such as the lucky direction (eho), north-pillow, and qibla

Current location and device heading are used only for direction calculation and are not used for other purposes.

3. Data Storage

  • Destination information (place name, address, coordinates), custom display names, saved status, and last-used timestamps are stored only on the user's device.
  • The "Daily Direction" seed is stored only on the user's device.
  • Current location and device heading are used only for calculation and are not stored.
  • The list of search suggestions and search text history are not stored.
  • The daily "Daily Direction" result itself is not stored.

4. Data Transmission and Apple MapKit

This app does not use its own server or any third-party search API. Place and address search uses Apple's built-in MapKit. The developer does not collect, store, or transmit search terms, search results, current location, or destination information.

  • Location information and destination information are not sent to the developer's server or any other external server.
  • This app does not use its own backend.
  • No data is sent to third-party advertising or analytics SDKs.
  • This app does not sync data to iCloud or any other external service.

This information is processed only on the user's device (searching a place name or address may involve a network request to Apple's MapKit service).

5. Third-Party Sharing

This app does not provide collected information to third parties.

6. Advertising

This app does not display advertising and does not use advertising SDKs.

7. Analytics

This app does not use analytics SDKs or other tracking tools.

8. Accounts and Login

This app does not use account registration or login features.
